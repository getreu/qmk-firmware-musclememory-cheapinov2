================================================================================
⚠️  CRITICAL: EEPROM RESET REQUIRED  ⚠️
================================================================================

Defaults ONLY load when EEPROM is initialized!

After flashing firmware, you MUST reset EEPROM using one of these methods:

METHOD 1: Bootloader Combo (Recommended)
  1. Press Q+W+E+T together (or Y+I+O+P)
  2. Keyboard enters bootloader mode
  3. Flash cheapino_vial.uf2 again
  4. On first boot, EEPROM resets automatically
  5. Test: Press Space+Enter (LED should turn pink)

METHOD 2: Vial GUI
  1. Open Vial application
  2. Go to Settings/Security tab
  3. Click "Reset EEPROM"
  4. Unplug and replug keyboard
  5. Check Combos tab - should show 6 combos

METHOD 3: BOOTSEL Button
  1. Unplug keyboard
  2. Hold BOOTSEL button on RP2040
  3. Plug in while holding BOOTSEL
  4. Flash cheapino_vial.uf2
  5. EEPROM resets on first boot
