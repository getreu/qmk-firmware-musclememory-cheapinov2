## Critical Issue: EEPROM Reset Required

⚠️ IMPORTANT: After flashing, you MUST reset EEPROM for defaults to load!

Methods:
- Press Q+W+E+T (or Y+I+O+P) to enter bootloader, reflash
- Use Vial GUI → Settings → Reset EEPROM
- Use BOOTSEL button, reflash firmware

Defaults only load when eeconfig_init_user() runs, which happens
on EEPROM initialization, NOT on every boot.
